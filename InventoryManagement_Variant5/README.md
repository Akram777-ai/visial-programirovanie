# Inventory Management — вариант 5
Автор: Анваров Акрам, группа ИС 24-22. Учебный JavaFX проект.

## Запуск
Установите JDK 17+ и Maven; в корне проекта выполните `mvn javafx:run`. Для изменения интерфейса откройте FXML в Scene Builder.

## Функции
Таблица, 12 стартовых записей, поиск по названию/ID, фильтр категории, добавление, редактирование, удаление, поступление и списание. Данные сохраняются в `~/inventory-management-data.tsv`. Ctrl+N — новый товар, Ctrl+S — сохранить, Ctrl+F — поиск. Ошибочные данные показывают Alert.

## Статус
Пример подготовлен как пробная версия; фактический запуск в JavaFX и тесты на ПК автора не заявляются. Иллюстрации отчёта — макеты, а не подтверждение выполнения.
